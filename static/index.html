How the pipeline works
01
Document Ingestion
12 professor review files loaded from Rate My Professors, cleaned of HTML noise and boilerplate.
02
Chunking
Reviews split into 500-character chunks with 100-character overlap to preserve context at boundaries.
03
Embedding + Vector Store
all-MiniLM-L6-v2 embeds each chunk into a 384-dimensional vector, stored in ChromaDB with source metadata.
04
Retrieval
Query is embedded and compared against all chunks via cosine similarity. Top-5 most relevant chunks retrieved.
05
Grounded Generation
Groq's Llama 3.3 70B generates an answer using only the retrieved chunks — source files cited in every response.
